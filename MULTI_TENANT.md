# 🏢 Sistema Multi-Tenant - Controle de Estacionamento

Este documento explica como configurar e usar o sistema multi-tenant para atender múltiplos clientes.

## 📋 Visão Geral

O sistema agora suporta **múltiplos clientes (estacionamentos)** em uma única instalação do Supabase. Cada cliente tem:

- ✅ Seus próprios veículos no pátio
- ✅ Seu próprio histórico
- ✅ Suas próprias configurações
- ✅ Seus próprios usuários
- ✅ Dados completamente isolados

## 🚀 Configuração Inicial

### 1. Executar o Script Multi-Tenant

1. Acesse https://app.supabase.com
2. Entre no seu projeto
3. Vá para **SQL Editor** → **New query**
4. Copie o conteúdo do arquivo `supabase_schema_multitenant.sql`
5. Clique em **Run**

Este script irá:
- Criar tabela `clientes`
- Adicionar coluna `cliente_id` em todas as tabelas
- Criar políticas de RLS para isolamento
- Criar funções utilitárias

### 2. Atualizar o Schema Existente (se já tiver dados)

Se você já estava usando o sistema, execute apenas as atualizações:

```sql
-- Adicionar tabela clientes
CREATE TABLE IF NOT EXISTS clientes (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  cnpj VARCHAR(20),
  razao_social VARCHAR(200) NOT NULL,
  nome_fantasia VARCHAR(200),
  email VARCHAR(200),
  telefone VARCHAR(30),
  endereco TEXT,
  ativo BOOLEAN NOT NULL DEFAULT true,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Adicionar cliente_id nas tabelas existentes
ALTER TABLE veiculos ADD COLUMN IF NOT EXISTS cliente_id BIGINT REFERENCES clientes(id) ON DELETE CASCADE;
ALTER TABLE historico ADD COLUMN IF NOT EXISTS cliente_id BIGINT REFERENCES clientes(id) ON DELETE CASCADE;
ALTER TABLE configuracoes ADD COLUMN IF NOT EXISTS cliente_id BIGINT REFERENCES clientes(id) ON DELETE CASCADE;
ALTER TABLE usuarios ADD COLUMN IF NOT EXISTS cliente_id BIGINT REFERENCES clientes(id) ON DELETE CASCADE;

-- Criar índices
CREATE INDEX IF NOT EXISTS idx_veiculos_cliente ON veiculos(cliente_id);
CREATE INDEX IF NOT EXISTS idx_historico_cliente ON historico(cliente_id);
CREATE INDEX IF NOT EXISTS idx_configuracoes_cliente ON configuracoes(cliente_id);
CREATE INDEX IF NOT EXISTS idx_usuarios_cliente ON usuarios(cliente_id);

-- Inserir cliente padrão (ID 1) para dados existentes
INSERT INTO clientes (id, razao_social, nome_fantasia)
VALUES (1, 'Cliente Padrão', 'Estacionamento Central')
ON CONFLICT (id) DO NOTHING;

-- Atualizar dados existentes para o cliente padrão
UPDATE veiculos SET cliente_id = 1 WHERE cliente_id IS NULL;
UPDATE historico SET cliente_id = 1 WHERE cliente_id IS NULL;
UPDATE configuracoes SET cliente_id = 1 WHERE cliente_id IS NULL;
UPDATE usuarios SET cliente_id = 1 WHERE cliente_id IS NULL;
```

## 📱 Como Usar

### Primeiro Acesso

1. Abra o sistema (`index.html`)
2. Você verá a tela **"Selecione o Cliente"**
3. Escolha uma das opções:
   - **Selecionar um cliente existente** → Vai para o login
   - **Login Direto** → Usa o cliente padrão
   - **Novo Cliente** → Cadastra um novo cliente

### Cadastrar Novo Cliente

1. Clique em **"➕ Novo Cliente"**
2. Preencha os dados:
   - Razão Social
   - Nome Fantasia
   - CNPJ
   - E-mail
   - Telefone
   - Usuário Admin
   - Senha Admin
3. Clique em **"✅ Cadastrar"**

O sistema automaticamente:
- Cria o cliente
- Cria configurações padrão (20 vagas, valores padrão)
- Cria o usuário admin

### Acessar um Cliente

1. Selecione o cliente na lista
2. Faça login com usuário e senha
3. O sistema carregará apenas os dados daquele cliente

### Trocar de Cliente

- No login: clique em **"🔄 Trocar Cliente"**
- Após logout: você volta para a seleção de clientes

## 🗄️ Estrutura do Banco de Dados

### Tabela: `clientes`

| Coluna | Tipo | Descrição |
|--------|------|-----------|
| id | BIGINT | ID único do cliente |
| cnpj | VARCHAR | CNPJ do estabelecimento |
| razao_social | VARCHAR | Razão social |
| nome_fantasia | VARCHAR | Nome fantasia |
| email | VARCHAR | E-mail para contato |
| telefone | VARCHAR | Telefone |
| endereco | TEXT | Endereço completo |
| ativo | BOOLEAN | Se o cliente está ativo |

### Todas as Outras Tabelas

Todas as tabelas agora têm a coluna `cliente_id`:
- `veiculos.cliente_id`
- `historico.cliente_id`
- `configuracoes.cliente_id`
- `usuarios.cliente_id`

## 🔐 Isolamento de Dados

O isolamento é garantido por:

1. **Filtro nas Queries**: Todas as consultas filtram por `cliente_id`
2. **Row Level Security (RLS)**: Políticas no banco filtram automaticamente
3. **Cliente em Memória**: O cliente selecionado fica armazenado no frontend

## 📊 Funções do Supabase

### `fetchClientes()`
Busca todos os clientes ativos

### `createCliente(cliente)`
Cria um novo cliente com configurações e usuário admin

### `updateCliente(id, updates)`
Atualiza dados de um cliente

### `setClienteAtual(cliente)`
Define o cliente atual na sessão

### `getClienteAtual()`
Retorna o cliente atual

## 🛠️ Gerenciamento

### Ver Todos os Clientes

No SQL Editor do Supabase:
```sql
SELECT * FROM listar_clientes();
```

### Criar Cliente Manualmente

```sql
SELECT criar_cliente(
  '00.000.000/0001-00',           -- CNPJ
  'Estacionamento XYZ Ltda',      -- Razão Social
  'Estacionamento XYZ',           -- Nome Fantasia
  'contato@xyz.com',              -- E-mail
  '(11) 99999-9999',              -- Telefone
  'Rua Exemplo, 123',             -- Endereço
  'admin_xyz',                    -- Usuário Admin
  'senha123'                      -- Senha Admin
);
```

### Desativar um Cliente

```sql
UPDATE clientes SET ativo = false WHERE id = X;
```

### Ver Dados de um Cliente

```sql
-- Veículos no pátio
SELECT COUNT(*) FROM veiculos WHERE cliente_id = X AND saida IS NULL;

-- Faturamento do mês
SELECT SUM(valor_cobrado) FROM historico 
WHERE cliente_id = X AND saida >= DATE_TRUNC('month', NOW());

-- Configurações
SELECT * FROM configuracoes WHERE cliente_id = X;

-- Usuários
SELECT * FROM usuarios WHERE cliente_id = X;
```

```sql
SELECT * FROM resumo_multi_cliente;
```

Retorna:
- Cliente ID
- Nome fantasia
- Veículos no pátio
- Vagas ocupadas/livres
- Saídas no mês
- Faturamento no mês

## 🔄 Migração de Dados Existentes

Se você já tinha dados antes do multi-tenant:

1. Execute o script `supabase_schema_multitenant.sql`
2. Os dados existentes serão vinculados ao cliente padrão (ID 1)
3. Crie novos clientes normalmente
4. Os dados antigos permanecem acessíveis

## ⚠️ Importante

### Segurança

- Em produção, use autenticação real do Supabase (JWT)
- Não armazene senhas em texto puro (use hash)
- Revise as políticas de RLS para seu caso de uso

### Performance

- Índices já estão criados para `cliente_id`
- Para muitos clientes, considere particionamento
- Monitore o tamanho das tabelas

### Backup por Cliente

```sql
-- Exportar dados de um cliente
COPY (SELECT * FROM veiculos WHERE cliente_id = X) TO STDOUT;
COPY (SELECT * FROM historico WHERE cliente_id = X) TO STDOUT;
```
